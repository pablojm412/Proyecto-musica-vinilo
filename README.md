## 🛠️ Tecnologías del Stack
El proyecto se desarrollará utilizando una arquitectura Full Stack que combina potencia y dinamismo:

*   **Frontend:** Angular (HTML5, CSS3, TypeScript).
*   **Backend:** C++ (Motor de alto rendimiento).
*   **Base de Datos:** (A definir según los requerimientos del backend).

---

## 📂 Estructura Sugerida
Para mantener el orden, el repositorio se dividirá en las siguientes carpetas:

*   `/frontend`: Todo el código referente a la interfaz de usuario en Angular.
*   `/backend`: Lógica del servidor, controladores y conexión a base de datos en C++.
*   `/docs`: Documentación técnica y esquemas de la base de datos.

---

## 💿 Características de la Tienda
*   Catálogo de vinilos musicales.
*   Clasificación por categorías y géneros (Hip-Hop, Trap, Rock, etc.).
*   Gestión de stock y precios.
